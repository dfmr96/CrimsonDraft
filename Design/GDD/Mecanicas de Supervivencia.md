# Mecanicas de Supervivencia

## Core Emotional Loop

**Ansiedad por escasez** - El jugador debe sentir que cada bala cuenta, cada decision tiene peso, y el combate es un costo, no una recompensa.

---

## Progresion Invertida

En la mayoria de RPGs, el jugador se vuelve mas poderoso con el tiempo.

En Crimson Draft:
- La progresion no es empoderamiento, es **desgaste**
- Los recursos disminuyen
- Los enemigos escalan
- El protagonista se deteriora
- La escasez es coherente con la tragedia

---

## Sistema de Infeccion / Exposicion

### Exposicion Ambiental al Krokonil

En ciertas zonas del barco:
- Hay polvo concentrado de [[Krokonil]]
- Permanencia prolongada activa un medidor interno

### Efectos progresivos:

| Nivel | Efecto |
|---|---|
| Leve | Temblor leve, ligera mejora de punteria |
| Moderado | Mejor punteria, reduccion de dolor recibido |
| Alto | Confusion momentanea, irritacion cutanea |
| Critico | Perdida de control, deterioro visible |

### Dilema Moral

El jugador puede decidir usar microdosis de Krokonil para:
- Mejorar punteria temporalmente
- Aumentar resistencia al daño
- Pero el contador de deterioro aumenta

> "Usas la droga para sobrevivir?" - Eso es horror moral.

## Sistema de Guardado: Telegrafo Morse

### Concepto

Las zonas de guardado son salas con un **telegrafo radio-telegrafico**. No es un save room magico — es parte del mundo. El telegrafo era usado para enviar mensajes en clave a la tripulacion entre compartimentos.

Justificacion: "Las lineas internas del barco siguen operativas. El sistema Morse aun transmite entre compartimentos."

### Tipo de telegrafo

**Radio telegrafico (Wireless Telegraphy)** — transmite Morse por ondas de radio. Requiere energia y antena operativa. Realista para un tanquero. Mismo sistema que uso el Titanic para pedir auxilio.

### Identidad sonora

Cada guardado produce el sonido del Morse: clic... clic... clic. Ese sonido es el equivalente psicologico a la musica de guardado de Resident Evil.

- El patron Morse es **siempre el mismo** al guardar
- Mas adelante el jugador puede descubrir que ese patron es un **mensaje oculto**
- Conexion subconsciente: el jugador escucho el patron cientos de veces sin saber que decia

### Integracion mecanica (opciones)

| Variante | Descripcion |
|---|---|
| Simple | Interactuas → transmite mensaje → guardado |
| Tactica | Necesitas **cinta de transmision** (consumible) |
| Temporal | La maquina tarda 3-5 segundos en transmitir |
| Riesgo | Genera ruido que puede atraer enemigos cercanos |

### Nombres tecnicos de salas

Cada sala de guardado tiene nombre militar:
- "Comms Relay 01"
- "Auxiliary Morse Station"
- "Internal Line B"

### Lore del telegrafo

Los telegrafos del barco pueden:
- Tener mensajes antiguos que nadie respondio
- Repetir señales automaticas
- Transmitir interferencias
- O enviar un mensaje que NUNCA deberia estar activo

### Tension narrativa

- El protagonista cree que esta enviando mensajes
- Pero nadie responde
- O peor: alguien responde... pero no es quien deberia
- Si la antena esta dañada → no sale señal
- Si alguien esta bloqueando la frecuencia → silencio
- Si USA esta monitoreando → pueden interceptar

### Simetria narrativa (ver [[Intro Cinematica]])

**Guardar = transmitir.** Cada vez que el jugador usa un telegrafo para guardar, esta repitiendo el acto de Mateo. El guardado deja de ser mecanico. Se convierte en acto narrativo.

En el final, cuando todo colapsa, el protagonista envia un ultimo mensaje antes del misil — usando el mismo sistema que uso para guardar toda la partida.

### Simbolismo

El telegrafo es:
- Comunicacion lenta
- Comunicacion unidireccional
- Comunicacion que puede no recibir respuesta

Perfecto para un juego sobre traicion y abandono.

## Gestion de Recursos

### Recursos del Juego

| Recurso | Funcion | Escasez |
|---|---|---|
| Balas 9mm | Ataque basico | Moderada |
| Municion pesada | Habilidades | Alta |
| Botiquines | Curacion | Alta |
| Antidoto (si se implementa) | Reducir exposicion | Muy alta |

### Competencia entre recursos

Si se implementa el sistema de antidotos:
- Antidoto compite con municion como recurso escaso
- Encontrar uno significa que NO encontraste balas
- Eso es survival puro

## El Barco como Sistema

### Ambiente reactivo

El [[El Marinera|Marinera]] no es estatico:
- Se inclina
- Se inunda
- Se desequilibra
- Sistemas electricos fallan

### Mecanicas ambientales

- Ciertas zonas se inundan con el tiempo
- Puertas se bloquean
- El sistema de ventilacion puede dispersar Krokonil
- Abrir compuertas puede liberar gas accidentalmente
- Contaminar nuevas areas es posible

Esto conecta con el sistema de objetivos reactivos existente.

---

## Muerte de Personajes

Si un miembro del party muere:
- Se pierde su arma pesada permanentemente
- Se pierden sus habilidades unicas
- Eso genera ansiedad real de perdida
- No hay revive magico
